TwoStack WM
============

This kwinscript of [KWin] is a minimum, tiling window manager, that
only allowing windows being tiles in one of these two stacks:

1. Main
2. Side

The Main stack is a larger portion at the right-hand side of a screen,
while Side area takes the rest of left-hand side of a screen.

It is as if each of Main and Side contains their own stack of windows,
and only the top-most can be seen. Hence the name.

[KWin]: https://invent.kde.org/frameworks/kwindowsystem

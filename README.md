TwoStack WM
============

This kwinscript of [KWin] is a minimum, tiling window manager
simplifies your window management by only allowing windows tiling in 2
stacks (tiling areas)

1. Main
2. Side

The Main stack is a larger portion at the right-hand side of a screen,
while Side area takes the rest of left-hand side of a screen.

It is as if each of each of the Main and Side areas contains their own stack
of windows, and only the top-most can bee seen. Hence the name.

Windows may be placed in either of Main or Side.

[KWin]: https://invent.kde.org/frameworks/kwindowsystem
